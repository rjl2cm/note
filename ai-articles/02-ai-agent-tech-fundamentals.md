## 神经网络

> 📝 *待补充*：神经元类比（输入信号→权重→激活函数→输出）；深度=多层；为什么层数多了就"更聪明"？

**职场比喻**：神经网络就像一个超大的"审批流"——每一层都是一个部门，每个部门对数据做一次加工，最终由"CEO层"给出决策。

---

## Transformer

> 📝 *待补充*：Self-Attention 机制（词与词之间的"注意力权重"）；为什么 Transformer 打败了 RNN？并行计算优势。

**关键论文**：*Attention Is All You Need*（Vaswani et al., 2017）

**职场比喻**：Attention 机制像是开会时"谁的发言最重要就给谁更多关注"，而不是把所有人的话等权重处理。

---

## 预训练与微调

> 📝 *待补充*：预训练（在海量文本上学习世界知识）→ SFT 指令微调（学会"好好回答问题"）→ 领域微调（针对企业私有知识）。

| 阶段 | 类比 | 目的 |
|------|------|------|
| 预训练 | 读遍图书馆 | 建立世界知识 |
| SFT 指令微调 | 参加礼仪培训 | 学会按格式、按要求回答 |
| 领域微调 | 入职专项培训 | 掌握公司专有知识和术语 |

## RLHF

> 📝 *待补充*：RLHF（基于人类反馈的强化学习）——人类标注员对回答打分，训练奖励模型，再用强化学习让大模型"追求高分"。

**职场比喻**：就像绩效考核——公司（人类）定规则、打分，员工（模型）慢慢学会怎么干才能得高分。

## RAG

> 📝 *待补充*：RAG（检索增强生成）工作流：Query → 向量检索相关文档 → 把文档塞进 Prompt → 模型基于文档回答；企业知识库场景举例。

**职场比喻**：RAG 就像给一个博学但记性不好的顾问，每次问他问题前先帮他把相关资料打印好放在桌上。

## Agent 的工作闭环

> 📝 *待补充*：ReAct 框架（Reasoning + Acting）；工具调用（Function Calling）；记忆分类（短期对话记忆 vs. 长期向量记忆）；多 Agent 协作架构。

**四步循环图**（待补充图示）：

```
感知（Perception）
    ↓
规划（Planning / Reasoning）
    ↓
记忆（Memory）← → 工具调用（Action / Tool Use）
    ↓
执行结果反馈 → 下一轮循环
```
